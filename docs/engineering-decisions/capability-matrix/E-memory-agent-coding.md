## 3. Prioritised implementation order

### 3a. Memory (top 10)

1. Close the `forget` hole (M18): clear matching `proposals`, extend me05 to scan every table plus raw db and WAL. Own code, small.
2. Fix label-starved recall (M7): clearance in the SQL `WHERE`, candidate pool 64..512. Adapt the pool formula from Anamnesis `crates/search/src/hybrid.rs` `candidate_pool_for_limit` (Apache-2.0).
3. Forget honesty (M19, M20): list known copies, encrypt backup, `forget_by_source`, tombstone for re-runs. Behaviour from openclaw `memory-provenance.md` (MIT, docs only); BUILD.
4. Query-relevant, budgeted context for reviews (M11): replace newest-50 in `kk-service` `memory_files()`. Adapt packer ideas from Anamnesis `crates/search/src/packer.rs` (budget, per-source diversity, tiebreak by recency in a score band).
5. Provenance origin class and recall-loop mark (M14): closed-set column, injected-memory fingerprints refused by `propose`. BUILD from openclaw spec.
6. Project scope column (M12), separate from labels.
7. Near-duplicate and conflict proposals (M3, M4): SimHash/LSH from Anamnesis `crates/store/src/semantic_dedupe.rs` (Apache-2.0), output as owner proposals only.
8. Local vectors plus RRF (M8, M9): RRF from Anamnesis `hybrid.rs`; vectors in SQLCipher with the memory label; rerank only over cap (idea from anything-llm `server/utils/memories/index.js`).
9. Read-time rescan and quarantine (M16), then retention-based ranking (M13) using the half-life formula in ghast-memory-os `src/kernel/retention.ts` (Apache-2.0), ranking only.
10. Own evaluation suites (M26): recall, as-of, forget completeness, starvation, poisoning; add LongMemEval only for quality of non-private recall.

### 3b. Coding mode and agent loop (top 10)

1. Pre-apply vault snapshot plus guarded undo (C4). Rebuild from OpenCode `packages/core/src/snapshot.ts` and Cline `session/checkpoint-restore.ts` behaviour (MIT, Apache); store in vault, not a shadow git directory.
2. Project test/lint oracle in the sandbox, before/after deltas (C5, C6). Concept from goose `agents/retry.rs` success checks (Apache).
3. Real unified diff with context (C10) using `similar` as in Codex `apply-patch/src/file_update.rs`.
4. Per-path lock, hash re-check, line ending and BOM preservation, fsync (C3). Ideas from OpenCode `file-mutation.ts` and `edit.ts` (MIT).
5. Multi-hunk, multi-file fix container with exactly-once per hunk (C1), grammar from Codex `apply-patch/src/parser.rs`; narrow normalised fallback only when unique (C2, behaviour from OpenCode `edit.ts` 49-56, 306-309).
6. Language closure beyond Python (C7).
7. Context compaction in the worker with taint join (A2): OpenHands `condenser/README.md` design and `event/condenser.py` (MIT), Hermes verbatim-user and anchor index from `agent/context_compressor.py` 954-1085 (MIT), goose `structured.rs` fields (Apache).
