# Independent audit (2026-11-04): findings validated against the code

The audit read the four handoff reports only (it could not open the private repository). Each finding below was checked against the code and tests by the builder. Status: CONFIRMED (a real defect or gap), PARTLY CONFIRMED, DISPROVED, UNKNOWN. Every fix has a test that fails on the old behaviour.

| P0-1 | A reproducer printing `REPRODUCED` is trusted; a patch is "confirmed" when the word disappears | CONFIRMED | `crates/kk-review/src/check.rs` `run_reproducer` accepted any script that printed the line twice. Test `c05` (crates/kk-review/tests/check.rs) fails with that behaviour (mutation M3: both controls off) and passes now | Fixed: (1) negative control: the script runs a third time with the cited file emptied and is rejected if it still prints `REPRODUCED`; (2) a `CONTROL_OK` line is required in the same run (the script must show the normal behaviour works); (3) a fix is accepted only if `CONTROL_OK` is still printed after the change; (4) each released finding states what it establishes and lists the SHA-256 of every sample file it was checked on (`release.rs`); model prompt updated (`job.rs`). Limits stay: a script can still print `CONTROL_OK` without asserting anything, so a fix that simply disables a feature can pass if the script does not assert the normal path; project tests are not run. That is owed work (coding mode: run the project's own tests in the sandbox before offering a fix) |
